
# Power BI Dashboard Setup Guide
# Amazon India Fashion Sales Analysis
# =====================================

## STEP 1: Import Data
1. Open Power BI Desktop
2. Click "Get Data" → "Text/CSV"
3. Select amazon_cleaned.csv
4. Click "Transform Data" to open Power Query Editor

## STEP 2: Data Transformations in Power Query
- Change 'date' column to Date type
- Change 'amount', 'order_revenue' to Decimal Number
- Change 'qty', 'is_cancelled', 'is_delivered' to Whole Number
- Change 'b2b' to True/False (Boolean)
- Create a Date Table (below)

## STEP 3: Create Date Table (DAX)
DateTable = 
CALENDAR(
    DATE(2022, 3, 1),
    DATE(2022, 6, 30)
)

Add columns to DateTable:
- Month = FORMAT(DateTable[Date], "MMMM")
- MonthNum = MONTH(DateTable[Date])
- Quarter = "Q" & QUARTER(DateTable[Date])
- WeekNum = WEEKNUM(DateTable[Date])

Then create relationship: DateTable[Date] → orders[date]

## STEP 4: DAX Measures (Create all in "Measures" table)

-- Core Measures --
Total Orders = COUNTROWS(orders)

Total Revenue = 
SUMX(
    FILTER(orders, orders[is_cancelled] = 0),
    orders[order_revenue]
)

Avg Order Value = 
DIVIDE([Total Revenue], 
       COUNTROWS(FILTER(orders, orders[is_cancelled]=0)))

Cancellation Rate = 
DIVIDE(
    COUNTROWS(FILTER(orders, orders[is_cancelled] = 1)),
    COUNTROWS(orders),
    0
)

Delivery Rate = 
DIVIDE(
    COUNTROWS(FILTER(orders, orders[is_delivered] = 1)),
    COUNTROWS(orders),
    0
)

Return Rate = 
DIVIDE(
    COUNTROWS(FILTER(orders, orders[is_returned] = 1)),
    COUNTROWS(orders),
    0
)

High Value Orders = 
COUNTROWS(FILTER(orders, orders[amount] > 1000 && orders[is_cancelled] = 0))

-- Time Intelligence Measures --
Revenue Last Month = 
CALCULATE(
    [Total Revenue],
    DATEADD(DateTable[Date], -1, MONTH)
)

MoM Revenue Growth = 
DIVIDE(
    [Total Revenue] - [Revenue Last Month],
    [Revenue Last Month],
    0
)

-- B2B Specific --
B2B Revenue = 
CALCULATE([Total Revenue], orders[b2b] = 1)

B2C Revenue = 
CALCULATE([Total Revenue], orders[b2b] = 0)

B2B Order Share = 
DIVIDE(
    CALCULATE(COUNTROWS(orders), orders[b2b] = 1),
    COUNTROWS(orders)
)

-- Fulfilment Measures --
Amazon Fulfilled Revenue = 
CALCULATE([Total Revenue], orders[fulfilment] = "Amazon")

Merchant Fulfilled Revenue = 
CALCULATE([Total Revenue], orders[fulfilment] = "Merchant")
